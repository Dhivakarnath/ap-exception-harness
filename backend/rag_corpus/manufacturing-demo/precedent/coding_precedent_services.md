# Manufacturing — Coded-Invoice Precedent: Contracted Services

Version: 1.1.0
Effective from: 2026-01-01

Prior contracted-services invoices coded and approved by a human, retained as
precedent for account 6500 (Professional Services). Each records the vendor, the
billing language, and the confirmed account.

## PlantCare — maintenance labour

PlantCare bills contracted plant-maintenance labour. These code to 6500
(Professional Services); separately billed spare parts code to 5000. A
"maintenance labour" or "service visit" line from PlantCare follows this
precedent: 6500 (parts 5000).

## CalibratePro — calibration services

CalibratePro bills calibration and metrology services. These code to 6500. A
"calibration", "metrology", or "gauge verification" line follows this precedent:
6500.

## InspectQ — non-destructive testing

InspectQ bills weld inspection and non-destructive testing. These code to 6500.
An "NDT", "weld inspection", or "pressure test" line follows this precedent:
6500.

## RefractoryCo — foundry crucible reline

RefractoryCo bills for a foundry crucible reline (refractory labour). The labour
codes to 6500; refractory materials separately billed code to 5000. A "crucible
reline" or "furnace reline" line follows this precedent: 6500 (materials 5000).

## PlantCare — labour plus parts (split)

A PlantCare invoice bundling maintenance labour and replacement parts was split:
labour to 6500 and parts to 5000. A mixed labour-and-parts invoice follows this
precedent: split, labour 6500, parts 5000.
