# Manufacturing — Vendor Contract Terms (coding-relevant extracts)

Version: 1.1.0
Effective from: 2026-01-01

Extracts from active manufacturing vendor agreements, retained because a
contract sometimes fixes how a vendor's spend is coded or split. These are
`doc_type` vendor_contract so retrieval can include them when a vendor-specific
term matters.

## 1. PlantCare — maintenance services agreement

PlantCare provides contracted plant maintenance under a services agreement. The
maintenance *labour* codes to 6500 (Professional Services); replacement *parts*
PlantCare separately bills code to 5000 (Raw Materials). A single invoice mixing
labour and parts is a split-coding case.

## 2. SteelWorks — materials supply agreement

SteelWorks supplies structural steel under a supply agreement, normally
PO-backed. On a non-PO SteelWorks invoice, after confirming no missing PO, the
materials code to 5000 and any separately billed inbound freight codes to 5100.

## 3. HeavyHaul — haulage agreement

HeavyHaul provides inbound haulage under a logistics agreement. Inbound haulage,
carriage, and demurrage code to 5100 (Freight In). Outbound movement, if any, is
out of scope and routes to a human.

## 4. RefractoryCo — refractory services agreement

RefractoryCo provides refractory relining under a services agreement. The
relining *labour* codes to 6500; refractory *materials* consumed, if separately
billed, code to 5000. This is the contractual basis for the foundry-crucible-
reline split.

## 5. CalibratePro — calibration agreement

CalibratePro provides calibration and metrology under an annual agreement. All
CalibratePro service fees code to 6500 (Professional Services); the agreement
has no materials component, so no split applies.
