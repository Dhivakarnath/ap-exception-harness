# Retail — Coded-Invoice Precedent: Software, SaaS, and Cloud

Version: 2.0.0
Effective from: 2026-01-01

Prior software and cloud invoices coded and approved by a human, retained as
precedent for account 7200 (Software Subscriptions) unless noted. When a new
non-PO invoice resembles one of these, the precedent is a valid citation. Each
entry names the vendor, the billing language, and the confirmed account.

## Datamesh Analytics — platform subscription renewal

Datamesh Analytics bills annually for an analytics-platform licence renewal.
These invoices have been coded to 7200 (Software Subscriptions). A "platform
licence renewal", "analytics subscription", or "annual plan" line from Datamesh
follows this precedent: 7200.

## Nimbus Cloud — infrastructure usage

Nimbus Cloud bills monthly for compute, managed storage, and bandwidth. These
have been coded to 7200 (Software Subscriptions). A "compute usage", "storage
and egress", or "managed database" line from Nimbus follows this precedent:
7200.

## Cortex API — metered usage

Cortex API bills metered API-usage fees. These have been coded to 7200. A "API
usage", "requests billed", or "usage overage" line from Cortex follows this
precedent: 7200.

## Helpdesk SaaS — per-seat subscription

Helpdesk SaaS bills a per-seat monthly subscription. These have been coded to
7200. A "per-seat subscription", "additional seats", or "monthly plan" line
follows this precedent: 7200.

## Ledgerly — accounting software subscription

Ledgerly bills an annual accounting-software subscription. This is coded to
7200 (Software Subscriptions), not 6500 — it is a software product, not an
accounting *service*. A "software subscription" or "annual licence" line from
Ledgerly follows this precedent: 7200.

## Datamesh Analytics — implementation services (split)

On one Datamesh invoice, a separately-itemised "implementation services" line
was split to 6500 (Professional Services) while the subscription stayed 7200.
A Datamesh invoice that separately and materially itemises implementation or
onboarding services follows this precedent: subscription 7200, services 6500.

## Perpetual licence below threshold

A one-time perpetual software licence at 1,200 (below the 2,500 threshold) was
expensed to 7200. A sub-threshold "perpetual licence" or "one-time licence"
line follows this precedent: 7200.

## Perpetual licence at threshold — routed to human

A perpetual software licence at 4,000 (at or above threshold) was routed to a
human for a capitalisation decision, not expensed to 7200. An at-or-above-
threshold perpetual-licence line follows this precedent: route to a human.
