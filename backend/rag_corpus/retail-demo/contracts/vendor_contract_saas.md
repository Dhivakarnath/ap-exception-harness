# Retail — Vendor Contract Terms: Software and Cloud (coding-relevant extracts)

Version: 2.0.0
Effective from: 2026-01-01

Extracts from active software and cloud vendor agreements, retained because a
contract sometimes fixes how a vendor's spend is coded, split, or capped. These
are `doc_type` vendor_contract so retrieval can include them when a
vendor-specific term matters.

## 1. Datamesh Analytics — enterprise subscription

Datamesh Analytics (analytics platform) bills an annual enterprise subscription
coded to 7200 (Software Subscriptions). The contract bundles a fixed block of
onboarding hours at no separate charge; because those hours are not separately
invoiced, the whole renewal codes to 7200 with no split. Only a separately and
materially invoiced professional-services statement of work splits to 6500.

## 2. Nimbus Cloud — committed-use agreement

Nimbus Cloud bills monthly infrastructure usage under a committed-use discount
agreement. All usage (compute, storage, egress) codes to 7200. The commitment
sets a monthly minimum; an invoice materially above the committed tier is not a
coding exception (still 7200) but a spend-review flag for the budget owner.

## 3. Cortex API — usage agreement

Cortex API bills metered usage under a pay-as-you-go agreement. All usage codes
to 7200. The contract has no services component, so a Cortex invoice never
splits to 6500.

## 4. Helpdesk SaaS — per-seat agreement

Helpdesk SaaS bills per-seat monthly under a subscription agreement coded to
7200. Seat additions mid-term are pro-rated and remain 7200. There is no
implementation fee under this contract, so no split applies.

## 5. Ledgerly — accounting software agreement

Ledgerly provides accounting *software* under an annual subscription coded to
7200 — not 6500. The contract is explicit that Ledgerly supplies a software
product, not accounting services, which is why the spend is a software
subscription and not a professional service.
