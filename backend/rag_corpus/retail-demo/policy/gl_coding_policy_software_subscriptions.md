# Retail — Coding Guide: Software Subscriptions (Account 7200)

Version: 2.0.0
Effective from: 2026-01-01

This guide covers coding of software, SaaS, cloud, and licence spend to account
7200 (Software Subscriptions). Software spend is where recurring billing,
bundled services, and hardware/software mixes create the most coding ambiguity,
so each clause draws the boundary explicitly. Every clause resolves to 7200
unless it redirects.

## 1. Software-as-a-service and seat subscriptions

Account 7200 — Software Subscriptions.

Monthly and annual SaaS fees, per-seat and per-user subscriptions, tiered
platform plans, and usage-based software billing are coded to 7200. A renewal of
an existing subscription is 7200. Adding seats to an existing subscription is
7200. The recurring nature and the fact that the deliverable is access to
software, not a physical good, both point to 7200.

## 2. Platform and application licence renewals

Account 7200 — Software Subscriptions.

Annual licence renewals for a software platform, application suite, or developer
tool are coded to 7200. A renewal is 7200 even when the invoice bundles standard
support and updates, because support tied to a software product is part of the
subscription. Only a *separately and materially invoiced* professional-services
engagement (custom implementation, bespoke integration work) splits out to 6500.

## 3. Cloud hosting and infrastructure

Account 7200 — Software Subscriptions.

Infrastructure-as-a-service and platform-as-a-service charges — compute,
managed storage, managed databases, bandwidth and egress, serverless usage — are
coded to 7200. Cloud storage and backup-as-a-service are 7200, in contrast to
*physical* storage media, which is hardware coded to 6420.

## 4. API usage and data-platform charges

Account 7200 — Software Subscriptions.

Metered API usage, analytics- and data-platform charges, data-feed
subscriptions, and event-ingestion or observability platform fees are coded to
7200. Variable, usage-based billing does not change the account: consumption of
a software platform is 7200.

## 5. Annual maintenance and support tied to software

Account 7200 — Software Subscriptions.

A maintenance or support contract that is tied to a specific software product —
version updates, patches, vendor support SLA — is coded to 7200 as part of the
software's cost of ownership. Contrast this with general professional consulting
that merely happens to touch software: advisory or implementation labour that is
separately invoiced is 6500.

## 6. Perpetual software licences below threshold

Account 7200 — Software Subscriptions.

A one-time perpetual software licence below the capitalisation threshold is
expensed to 7200. Although it is not recurring, it is still software spend and
belongs in 7200 when expensed.

## 7. Perpetual licences at or above threshold

Route to a human — capitalisation decision.

A perpetual software licence at or above the capitalisation threshold may be a
capital asset rather than an expense. Do not expense it to 7200 automatically;
route it to a human for a capitalisation decision. This policy does not
authorise capitalising an asset on its own.

## 8. Software bundled with onboarding or implementation

Split — 7200 for software, 6500 for separately-invoiced services.

When a software invoice bundles a subscription with an onboarding, training, or
implementation service, code the subscription to 7200 and, if the services are
separately and materially invoiced as their own line, split that portion to 6500
(Professional Services). If the services are trivial, inseparable, or not
separately priced, the whole invoice stays 7200. Never split out a services line
that the vendor did not itemise.

## 9. What does not belong in 7200

Computer hardware, peripherals, and physical storage are 6420, not 7200.
Professional-services labour that is separately invoiced is 6500. A
capitalisable perpetual licence at or above threshold routes to a human.
Internet-access and telecom *utility* bills are out of scope and route to a
human — connectivity is a utility, not a software subscription.
